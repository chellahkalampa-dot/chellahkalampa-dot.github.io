Useful Kali commands

Safe examples for inspecting your own machine and local lab.

Quick reference
Show network interfaces and IP addressesip -br addr
Show the routing tableip route
Show listening TCP and UDP socketsss -lntup
Check your local website responsecurl -I http://127.0.0.1:8000/
Start a local-only website previewpython3 -m http.server 8000 --bind 127.0.0.1

Practice responsibly: Only scan, test or analyse devices, networks and applications that you own or have explicit permission to assess. These notes are educational and are not permission to test third-party systems.
